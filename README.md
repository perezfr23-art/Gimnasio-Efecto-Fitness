Efecto Fitness 💪
📌 Descripción

Efecto Fitness es un proyecto de página web desarrollado para presentar un gimnasio y sus servicios de entrenamiento.

El objetivo principal del sitio es brindar información sobre el gimnasio, mostrar los diferentes servicios ofrecidos y permitir que los usuarios puedan conocer más sobre Efecto Fitness y ponerse en contacto.

La página fue desarrollada como parte de un proyecto personal para poner en práctica conocimientos de desarrollo web y diseño de sitios responsivos.

🌐 **Demo online**

Podés visitar el sitio publicado en Vercel: https://gimnasio-efecto-fitness.vercel.app/

🌐 Secciones del sitio

El sitio web cuenta con las siguientes secciones:

Inicio: presentación principal de Efecto Fitness.
Sobre mí: información sobre el gimnasio y/o el entrenador.
Servicios: descripción de los diferentes entrenamientos y servicios disponibles.
Proyectos: sección destinada a mostrar trabajos, experiencias o resultados.
Contacto: espacio para que los usuarios puedan comunicarse y obtener más información.
🛠️ Tecnologías utilizadas

Para el desarrollo de este proyecto se utilizaron las siguientes tecnologías:

HTML5: estructura y contenido del sitio web.
CSS3: estilos y diseño visual.
SCSS: organización y optimización de los estilos.
Bootstrap: creación de componentes y diseño responsive.
📱 Diseño Responsive

La página está diseñada para adaptarse a diferentes tamaños de pantalla, permitiendo una correcta visualización en:

Computadoras 💻
Tablets 📱
Teléfonos móviles 📲
🎯 Objetivo del proyecto

El objetivo de Efecto Fitness es aplicar los conocimientos adquiridos durante el curso de desarrollo web, utilizando buenas prácticas en la estructura del código, estilos y diseño responsive.
